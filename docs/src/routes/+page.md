# Zeno UI

Build Beautiful Apps with **Zeno UI**

A collection of beautiful, accessible, and customizable components built with SvelteKit and Tailwind CSS. Copy, paste, and customize to your heart's content.

## Features

- **Customizable** - Built with Tailwind CSS and CSS variables. Customize colors, spacing, and more to match your brand.
- **Accessible** - Built with accessibility in mind. All components follow WAI-ARIA design patterns and best practices.
- **Developer Experience** - Copy and paste components into your apps. Built with TypeScript and designed for developer productivity.

## 47 Components and counting

From basic buttons to complex data tables. Everything you need to build modern web applications.

[Browse Components](/docs/components/accordion) | [View on GitHub](https://github.com/Mhamad6000/zeno-ui)

## Quick Start

```bash
pnpm dlx zeno-ui@latest init
```

This will install and configure Zeno UI for your project.

## Installation

```bash
pnpm dlx zeno-ui@latest add button
pnpm dlx zeno-ui@latest add card
pnpm dlx zeno-ui@latest add input
```

## Example

```svelte
<script lang="ts">
	import { Button } from "$lib/components/ui/button";
</script>

<Button>Click me</Button>
```
