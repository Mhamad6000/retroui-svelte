## Customization

You can customize the colors by modifying the CSS variables in your `app.css` file. The values are in HSL format without the `hsl()` wrapper.

### Adding New Colors

To add new colors, define them as CSS variables:

```css
:root {
	--success: 142.1 76.2% 36.3%;
	--success-foreground: 355.7 100% 97.3%;
	--warning: 32.5 94.6% 43.7%;
	--warning-foreground: 355.7 100% 97.3%;
}
```

Then add them to your Tailwind configuration:

```javascript
// tailwind.config.js
module.exports = {
	theme: {
		extend: {
			colors: {
				success: {
					DEFAULT: "hsl(var(--success))",
					foreground: "hsl(var(--success-foreground))",
				},
				warning: {
					DEFAULT: "hsl(var(--warning))",
					foreground: "hsl(var(--warning-foreground))",
				},
			},
		},
	},
};
```

### Using Colors in Components

You can use the colors in your components with Tailwind classes:

```svelte
<div class="bg-primary text-primary-foreground">
	Primary background with primary foreground text
</div>

<div class="bg-success text-success-foreground">
	Success background with success foreground text
</div>
```

Or with CSS:

```css
.my-component {
	background-color: hsl(var(--primary));
	color: hsl(var(--primary-foreground));
}
```

## Color Tools

### Generating Color Palettes

You can use tools like [HSL Color Picker](https://hslpicker.com/) or [Coolors](https://coolors.co/) to generate and test color palettes.

### Converting Colors

When adding custom colors, make sure to convert them to HSL format without the `hsl()` wrapper:

- RGB(59, 130, 246) → HSL(217.2 91.2% 59.8%) → `217.2 91.2% 59.8%`
- HEX(#3b82f6) → HSL(217.2 91.2% 59.8%) → `217.2 91.2% 59.8%`
